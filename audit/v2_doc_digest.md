# Выжимка из дизайн-документа v2 (U073) — что касается v1 (F401)

Источник: «Тепличный логгер на U073» (HTML владельца, разделы 01, 05, 15, 16, 18).
Документ описывает **вторую** версию платы; здесь — только то, что подтверждает
находки аудита v1 или добавляет требования, применимые к v1 без смены железа.

## Факты о v1 из документа

- Плата v1 — **BlackPill (STM32F401)** + периферия. Ток сна F401 в STOP документ
  оценивает в ~50–100 мкА; на макетке ловили 1.2 мА от линий SPI перед сном (уже исправлено).
- **VBAT посажен на VDD**, резерва нет → при замене банки календарь теряется (A6 подтверждён).
- MSC в v2 — только чтение. В v1 владелец решил стирать архив удалением файла через USB,
  то есть MSC в v1 остаётся на запись. Это осознанное расхождение версий.

## Совпадения с аудитом v1 (независимое подтверждение)

| Документ v2 | Аудит v1 | Статус в v1 |
|---|---|---|
| Пока есть VBUS — флеш не трогать | A3 / C1 | П1: флаг занятости; П4: поднимать USB после записи |
| Стирание сектора каталога каждый час — окно потери всего файла | C3 | П1: запрет записи при VDD < 2.9 В; архитектура не менялась |
| BOR не настроен | A7 | П4 / владелец (option bytes) |
| IWDG: максимум 32.8 с, час сна не переживёт | A4 | П4 — см. ниже про F401 |
| Флаг «время не установлено» в каждой строке | A6 | П4 |
| LSE: таймаут ≥ 10 с, при отказе — LSI с отметкой в логе | A5 | П4 |
| Восстановление зависшей I2C (9 тактов SCL) | B6 | был «только если подтвердится» → **делать** (см. ниже) |

## Новое для v1 (переносится без смены железа)

1. **Счётчик перезагрузок и причина сброса в каждой строке** (ТЗ п. 9) — иначе тихие
   перезагрузки в поле невидимы.
2. **Восстановление I2C** (ТЗ п. 17). Обоснование документа ровно про v1: ключ PB0
   снимает питание датчиков каждый час; ведомый, обесточенный посреди байта, держит
   SDA в нуле. Таймаут на транзакцию + 9 тактов SCL + STOP + переинициализация;
   не помогло — снять питание датчиков и повторить.
3. **Карантин неисправного датчика** (ТЗ п. 16). N = 3 отказа подряд → не подавать
   питание датчикам M часов, в строку — код ошибки. Залитый разъём каждый час сажает
   ключ и LDO в ограничение тока и съедает бюджет за недели.
4. **Сырые отсчёты АЦП и напряжение рейла в строке** (ТЗ п. 8) — единственный способ
   пересчитать почву задним числом, если калибровка уплыла.
5. **Архитектура записи** (документ §16.3, ТЗ пп. 2–4) — каталог FAT обновлять только
   по событию VBUS, в горячем пути только программирование страниц по чистой памяти,
   стирание следующего сектора заранее, указатель записи в backup-регистрах. Самая
   ценная и самая крупная правка; в v1 — отдельная волна по решению владельца.

## Особенность F401 для IWDG

У F401 нет опции заморозки IWDG в STOP (у U073 есть `IWDG_STOP`). Запущенный IWDG
остановить нельзя, а максимум периода ~32 с. Значит в v1 сторож возможен только с
пробуждением по RTC чаще периода IWDG — на короткий «пинок» без замера. Стоимость
мала (доли мкА в среднем при пробуждении ~1 раз в 20–25 с), но её надо замерить.
