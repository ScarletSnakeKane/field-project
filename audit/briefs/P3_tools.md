# П3 — Инструменты (волна 1)

Ветка: `fix/p3-tools`. Сначала прочитать `audit/briefs/_common.md`.

## Цель
Инструменты не могут стереть архив, которого не сохранили, не показывают старые
данные как новые и не обещают батарее срок, которого не будет.

## Владение
Только `tools/` (кроме `tools/syncheck.sh` — его не трогать). Прошивку и тесты не править.
Скрипты работают у владельца на Windows (Git Bash, Python 3, CubeIDE) — не ломать это:
никаких Linux-only утилит, пути с пробелами, CRLF.

## Находки и направление правки

- **D1 [КРИТ] `--wipe` после частичного снятия.**
  Стирание — только отдельным вторым прогоном, после того как хост сохранил дамп и
  проверил, что `len == fsize` (снят весь файл, не окна). Если файл снят окнами —
  `--wipe` отказывается с понятным сообщением. Стирание в прошивке-дампере — только
  если `f_read` вернул `FR_OK`.
- **D2 [КРИТ] `analyze_run.py` завышает срок.**
  Процент считать той же кривой, что и прошивка (`Core/Src/battery_curve.c` —
  перенести таблицу в Python с комментарием-ссылкой, или парсить таблицу из `.c`),
  срок — от текущего заряда. `--compare` — по одной кривой для обоих прогонов.
  Проверка: `audit/data/nan_first.txt` даёт ~42 суток, а не ~104.
- **D3 [ВЫС] сводка по старому файлу.** Перед снятием удалять/переименовывать
  прошлый `build/data.txt`; при 0 байт — ненулевой код выхода и явное сообщение.
- **D4 [СРЕД] Ctrl+C во время прошивки дампера.** `trap` на INT/TERM/EXIT, отметку
  «дампер прошит» ставить до начала прошивки; откат всегда при выходе.
- **D5 [СРЕД] CRLF и забытый дампер.** Патч сохраняет окончания строк исходника
  байт-в-байт; восстановление — из сохранённой копии, сверка хешем. Опционально:
  `tools/hooks/pre-commit`, отвергающий коммит с маркером `ВРЕМЕННЫЙ ДАМПЕР`
  (не устанавливать автоматически, только файл и строка в отчёте, как поставить).
- **D7 [СРЕД] повторы прошивки.** `flash_now` не глотает вывод программатора;
  постоянная ошибка (нет ST-Link, нет файла) → немедленный выход с кодом, не 70 минут.
  Подсказки про ловлю окна — честные: «воткни USB платы или держи KEY».
- **D8 [НИЗ] `nan` и 85 °C в диапазонах.** Сводки пропускают `nan` при min/max/среднем
  и считают их отдельно.

## Готово, когда
Общий критерий (пункты про прошивку — синтаксис/тесты не должны сломаться) плюс:
`bash -n` по каждому `.sh`, `python3 -m py_compile` по каждому `.py`; для D2, D3, D8 —
прогон на `audit/data/` с выводом в отчёте «было → стало».
