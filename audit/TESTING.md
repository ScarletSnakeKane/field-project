## Плата
STM32F401 (проект собран под F401RET6; BlackPill F401CEU6 совместим, CCU6 — нет).
Пины: PB0 ключ датчиков (HIGH = выкл), PB8/PB9 I2C (AHT20 0x38 + BMP280 0x76/0x77),
PA8 1-Wire DS18B20, PA1 почва (ADC1_IN1), PA2 делитель батареи (ADC1_IN2, ×2),
PA4–PA7 SPI-флеш SST26VF016B (CS, SCK, MISO, MOSI), PA9 VBUS-детект, PA11/PA12 USB,
PA0 кнопка KEY, PC14/PC15 LSE, PA13/PA14 SWD.

## Как работает прошивка (кратко)
- Раз в час: питание датчиков → замер → одна двоичная запись в кольцевой журнал на флеш → сон.
  Каждые ~15 с короткое пробуждение только для сторожа IWDG (без замера).
- Кнопка — внеочередной замер. **Вокруг USB-сессии не меряем** (прибор вынут из земли):
  вставка кабеля будит без замера, часовые замеры при открытой сессии пропускаются;
  зарядка без хоста через 10 с отпускает плату, расписание идёт обычно.
- По USB — виртуальный FAT16-том `FIELDSENSOR` только для чтения: `data.txt` (CSV, 23 колонки),
  `info.txt`, пока жив импорт — `data_old.txt`. Диск появляется через ~1–13 с (растёт с архивом).
- Журнал на отдельной SPI-флеш: перепрошивка МК архив **не стирает**. Ёмкость ~3.7 года.

## Состояние на 2026-10-28
- Плата собрана, первые данные получены — **на старой прошивке** (13 колонок, интервал ~40 с,
  дата сборки 2026-08-24). AHT20 и DS18B20 отвечают.
- ⚠️ `vbat = 4.84 В` на старой прошивке — выше максимума 18650 (4.2 В). Выяснить: питание
  не от банки (USB/ЛБП) или делитель PA2 не 1:1. Новая прошивка пишет `vbat`, `vdd`, `bat_raw` —
  по ним видно сразу.
- Следующий шаг: прошить ветку (ST-Link `./tools/dev.sh build && ./tools/dev.sh flash`
  или DFU по USB-C: BOOT0 + NRST → STM32CubeProgrammer → USB), прислать первые строки
  `data.txt` и `info.txt`.

## План испытаний
1. Первые строки на новой прошивке: `aht_read_st`, `air_xchk`, `ds_err` (5 = клон DS18B20 с
   иными служебными байтами), `soil_valid`/`soil_raw`, `vbat`/`vdd`, `lse_ok`, `time_ok`.
2. Сутки на столе от банки, **без USB и ST-Link**: ~24 строки, время без дыр; подключение
   телефона лишней строки не даёт; кнопка — даёт.
3. Ток сна амперметром в разрыв банки, ST-Link физически отключён.
4. Несколько выдёргиваний банки во время работы — файл читается, потеряно ≤ 1 строки.
5. Телефон заказчика: диск появляется, файл копируется.
6. Перед полем: BOR Level 3 в option bytes (STM32CubeProgrammer → OB → `BOR_LEV`).
7. Всё прошло — слить PR #7 в `main`.
